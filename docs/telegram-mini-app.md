# Telegram Mini App

Mini App живёт по адресу `/tg` и работает на **том же бэкенде**, что и
веб-версия: общие таблицы, общий AI-слой, общий расчётный движок. Отдельного
сервиса нет — это осознанное решение из [плана](./implementation-plan.md).

Оболочка v2 — пять вкладок снизу; согласованная спецификация со всеми
отличиями от макета — [`miniapp-v2.md`](./miniapp-v2.md).

## Что умеет прототип

| Вкладка | Возможности |
|---|---|
| **Сегодня** | Кольцо энергии, полосы белка/жиров/углеводов/клетчатки относительно целей — сразу, без раскрытия; мини-график тренда веса; строка на инбокс, только если там что-то есть; карточка «что съесть сейчас»; список приёмов пищи |
| **Дневник** | Заглушка — приёмы пищи по дням с фото и макро-балансом строятся отдельно |
| **Камера** | Снимок или текст → мгновенный разбор → уровень уверенности словами (высокая/средняя/низкая), у неуверенного разбора — диапазон и уточняющий вопрос под итогом → правка порции → сохранение |
| **План** | Заглушка — прогресс, динамика веса и адаптивная цель строятся отдельно |
| **Профиль** | Заглушка — цели, измерения и настройки пока в веб-версии (`/app/settings`) |

Фото-инбокс (снимки, присланные боту, не разобранные сразу) в v2 — не
вкладка, а экран, на который ведёт строка с «Сегодня»: раздел «Три отличия
от макета» в `miniapp-v2.md`.

Дополнительно: привязка аккаунта одноразовым кодом, тема Telegram (светлая и
тёмная), нативная кнопка MainButton, тактильная отдача, режим «скрыть калории».

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Добавьте токен в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   ```
3. У BotFather: `/newapp` → выберите бота → укажите URL `https://jivoetelo.ru/tg`.
4. Перезапустите приложение: `docker compose up -d --build`.

Без `TELEGRAM_BOT_TOKEN` API Mini App отвечает `503 not_configured` — это
защита от случайного запуска без проверки подписи.

## Безопасность: проверка initData

Данные, которые Mini App получает от Telegram (`initData`), проверяются **на
сервере** библиотекой [`@telegram-apps/init-data-node`](https://www.npmjs.com/package/@telegram-apps/init-data-node):
HMAC-SHA256 с ключом, производным от токена бота, плюс проверка срока жизни
подписи (1 час). Клиентским данным без подписи не доверяем — раздел 17 спеки.

Каждый запрос к `/api/tg/*` передаёт `initData` в заголовке
`x-telegram-init-data`; маршрут заново проверяет подпись — сессионных кук нет.

Проверено тестами: подделка `user.id` в подписанных данных, подпись чужим
токеном, просроченная подпись и данные без подписи отклоняются.

## Привязка аккаунта

Пароль внутри Telegram не спрашиваем. Поток такой:

1. Пользователь в веб-версии открывает **Настройки → Telegram** и жмёт
   «Получить код» — генерируется 8-символьный код на 15 минут.
2. В Mini App вводит код → `POST /api/tg/link` привязывает `telegram_user_id`.
3. Дальше вход автоматический; код гасится после первого использования.

Отвязать можно там же в настройках — доступ Mini App пропадает сразу.

## API

Все маршруты требуют заголовок `x-telegram-init-data`.

| Маршрут | Назначение |
|---|---|
| `GET /api/tg/today` | Итоги дня, цели, список приёмов пищи |
| `POST /api/tg/analyze` | Разбор еды (multipart: `mode=text\|photo`) |
| `POST /api/tg/meals` | Сохранение приёма пищи |
| `GET /api/tg/suggest` | «Что съесть дальше» — остаток дня считает сервер |
| `POST /api/tg/link` | Привязка аккаунта по коду |

Коды ошибок: `401 invalid_signature`, `403 not_linked`, `503 not_configured`.

## Дизайн

Палитра берётся из `themeParams` Telegram (переменные `--tg-*`), поверх идут
фирменные акценты «Живого Тела»: коралловый акцент, тёплая бумага, серифные
цифры. Продукт узнаётся без логотипа, но не спорит с темой пользователя.
Иконки — собственный SVG-набор с единой толщиной штриха, без эмодзи
(раздел 10.7 спеки). Анимации уважают `prefers-reduced-motion`.

Скриншоты: [`screenshots/`](./screenshots/) — `tg-today.png`, `tg-add.png`,
`tg-draft.png`, `tg-suggest.png`, `tg-today-dark.png`. Сняты до перехода на
оболочку v2 — соответствуют прежним названиям вкладок, актуализация ждёт
следующего прогона `tests/e2e/telegram.mjs`.

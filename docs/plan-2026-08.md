# План работ по итогам исследования

Источник: `docs/research-2026-08.md`. Юридические пункты (7.1, локализация ПД)
исключены по решению — они не про код.

Порядок задан приоритетом заказчика: паритет клиентов → голос → штрихкоды →
база продуктов → остальное.

## Волна 1. Паритет веб ↔ Mini App

- [x] **1.1. Справочник продуктов в веб-форме добавления.** Модуль
  `lib/food-reference.ts` вызывается только из Mini App. Ровно поэтому в вебе
  появилась запись «Салат овощной, 300 г — 0 ккал».
- [x] **1.2. Подсказочный цвет Mini App выводить самим**, а не брать из темы
  Telegram: контраст перестаёт зависеть от темы пользователя.
- [x] **1.3. Живело и серия в веб-кабинете.** Сейчас человек с ноутбука не
  видит ни счётчика, ни вех, хотя вехи открывают ему разделы.
- [x] **1.4. Недельный обзор в Mini App.** Экран «План» отправляет за ним в
  веб-версию; для живущего в Telegram обзора не существует.

## Волна 2. Голосовой ввод

- [x] **2.1. Слой распознавания речи** с провайдером-заглушкой, как у почты и
  AI: без ключей работает «не настроено», с ключами — настоящая расшифровка.
- [x] **2.2. Голосовые в боте** вместо отказа.
- [x] **2.3. Запись голосом** (MediaRecorder) — и в Mini App, и в кабинете: общий
  хук на оба клиента, как у камеры.

## Волна 3. Штрихкоды

- [x] **3.1. Своя база штрихкодов.** Единой открытой базы российских продуктов
  с составом не существует — значит собираем свою, пополняя её тем, что
  вводят люди.
- [x] **3.2. Сканер в вебе** через `BarcodeDetector`, с честным сообщением
  там, где браузер не умеет.
- [x] **3.3. Сканер в Mini App** — на том же `BarcodeDetector` поверх своего
  видоискателя, а не на `showScanQrPopup`: тот описан только для QR и не
  работает в Desktop- и Web-клиентах вовсе.

## Волна 4. База российских продуктов

- [x] **4.1. Расширение справочника** с 145 позиций до 301 — в основном
  готовыми блюдами: люди едят борщ и котлету с пюре, а не «говядину отварную».
- [x] **4.2. Поиск на сервере** — по базе штрихкодов. Граница прошла не по
  размеру справочника, а по природе данных: курируемая основа рациона
  (16 КБ в сжатом виде) осталась в бандле и ищется мгновенно, растущая база
  товаров живёт на сервере.

## Волна 5. Остальное

- [x] **5.1. Семь событий аналитики** — без них воронку после запуска
  восстановить нечем.
- [x] **5.2. Упрощённый режим учёта.** Приверженность 97% против 49% при той
  же потере веса на шести месяцах.
- [x] **5.3. Метрика «дни с двумя и более записями»** — лучший предиктор
  результата, в отличие от длины серии.
- [x] **5.4. Контраст.** `--muted` → `#6b6c65`, плюс отдельный `--coral-text`
  для кораллового текста: фирменный коралловый как текст давал 3,13 на белом.
  Было 115 элементов ниже нормы AA на тринадцати публичных страницах, стало 0.
- [x] **5.5. Чекбоксы 13×13 → норма** (24×24 у всех переключателей и галочек).
- [x] **5.6. Первый экран кабинета у нового пользователя.**

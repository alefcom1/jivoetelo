# Работа с этим репозиторием

## Оплата работы агентов — всегда уточнять до запуска

**Прежде чем настраивать что-либо, что расходует токены, спросите у владельца,
за счёт чего это оплачивается: подписка или баланс API.** Не выбирайте сами и
не наследуйте выбор из существующего кода.

Вход `anthropic_api_key` в `claude-code-action` списывает деньги с баланса
API-аккаунта; вход `claude_code_oauth_token` использует подписку Pro/Max.
Строки в YAML различаются одним словом, последствия — нет.

Это правило написано по факту: ночной конвейер контента унаследовал
`anthropic_api_key`, второй же прогон съел остаток баланса, а следующие
четыре падали за 350 мс с `Credit balance is too low`. Снаружи это выглядело
как поломка конвейера, и на её поиск ушло три ненужные правки подряд.
Настоящая причина была видна только после `show_full_output: true`.

Сейчас конвейер работает на подписке — `CLAUDE_CODE_OAUTH_TOKEN`
(`.github/workflows/content.yml`). Токен берётся командой `claude setup-token`.

Отдельно: `ANTHROPIC_API_KEY` в `.env` — это **другое**. Он про разбор еды в
самом приложении и идёт через прокси-воркер (`docs/ai-proxy.md`). К агентам
CI отношения не имеет, путать их нельзя.

## Ночной конвейер контента

Устройство, очередь на 90 позиций и правила для агента — в
`docs/seo-pipeline.md`. Коротко: три позиции разных видов за ночь, запуск в
00:00 МСК, каждая в своей ветке `content/<дата>-<slug>`, ничего не
публикуется автоматически.

## Проверки

`npm test` (тесты node:test), `npm run lint`, `npm run build`. Прогонять все
три перед коммитом.

Миграции в `drizzle/` — идемпотентные: свой раннер (`deploy/migrate.sh`)
оборачивает каждый файл в транзакцию и требует завершающую `;`. Для
ограничений таблиц используется `DO $$ … EXCEPTION WHEN duplicate_object …`,
потому что `ADD CONSTRAINT IF NOT EXISTS` в PostgreSQL нет.
